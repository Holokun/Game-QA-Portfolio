# Keybindings

## Default Key Bindings

### Movement

- Forward: `W`
- Back: `S`
- Left: `A`
- Right: `D`
- Jump: `Space`
- Crouch: `C`
- Sprint: `Shift`

### Gameplay

- Kick: `Q`
- Shoot: `Left Mouse Button`
- Ability: `Right Mouse Button`
- Heal: `H`
- Reload: `R`
- Interact: `E`

### Heroes

- Hero 1: `1`
- Hero 2: `2`
- Hero 3: `3`

## Buttons

### Reset to Default
- Type: Button
- States: Default, Hover

### Back
- Type: Button
- States: Default, Hover
- Returns to: Settings

## Observed UI

- Each action is displayed together with its current key or mouse-button binding.
- The bindings are presented in two columns.
- `Reset to Default` is available at the bottom of the screen.
