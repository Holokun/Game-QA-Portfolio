# Main Menu

## Buttons

### New Game
- Type: Button
- States: Default, Hover
- Action: Starts a new game

### Settings
- Type: Button
- States: Default, Hover
- Action: Opens the Settings screen

### Quit
- Type: Button
- States: Default, Hover
- Action: Exits the game

### Discord
- Type: Button
- States: Default, Hover
- Action: Opens the DEEPWARD Discord invite
- External link: https://discord.com/invite/ydB8TCEzcb

### Wishlist
- Type: Button
- States: Default, Hover
- Action: Opens the DEEPWARD Steam store page
- External link: https://store.steampowered.com/app/4709270/DEEPWARD/

### Send Feedback
- Type: Button
- States: Default, Hover
- Action: Opens the DEEPWARD feedback form
- External link: https://docs.google.com/forms/d/e/1FAIpQLSevYzpEnORy7sRAUEx2asLq6uXzG6CXDfYBE7FcCNeBCxGnfg/viewform

## Additional UI

- Game logo/title — top-left
- Build version — top-right
- Copyright notice — `© 2026 ECHOFALL GAMES. CO-DEVELOPED WITH HGAMES-ARTWORKS`
- Animated background with light flickering
- Background music

## Navigation

- `Settings` → Settings screen
- `Discord` → External Discord invite
- `Wishlist` → External DEEPWARD Steam store page
- `Send Feedback` → External feedback form
